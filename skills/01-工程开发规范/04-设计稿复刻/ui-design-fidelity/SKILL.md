# 设计稿差异快速定位与修复

这份 Skill 从投顾学院项目的实际修复和失败候选提炼。目标是**先识别差异类型，再读对应案例并复用已证实的办法**，避免每次从零扫 CSS、换字体或重跑设备。项目需求、设计源和已有证据仍优先；案例的像素、数值与阈值不能直接套到新项目。看大图时同时使用 `$image-analysis-optimizer`，预览不进入正式评分。

## 先用症状定位

| 观察到的问题 | 第一轮先查 | 对应案例 |
| --- | --- | --- |
| 整页分数高，标题、按钮或图标紧区低 | 固定 ROI、Sketch 可见墨迹、真实字体与图标 `viewBox`；空白区是否掩盖局部 | [字体与素材](references/字体素材与数据.md)、[几何与组件](references/几何组件与图表.md) |
| 卡片、弹窗、标签整体错位或长文遮挡 | 源图外沿、父子盒 `x/y/宽/高`、计算样式、全局 margin、底部锚定 | [几何与组件](references/几何组件与图表.md) |
| CSS 候选截图逐字节不变 | `CSS.supports`、`getComputedStyle`、Vue scoped 编译选择器、实际前台节点、截图时序；CDP 注入 `rpx` 可能无效 | [跨端与取证](references/跨端与取证.md) |
| H5 改善而 Android 退步 | 正式包/WGT 版本、设备原屏、WebView 字体与亚像素栅格；用目标端决定是否保留 | [跨端与取证](references/跨端与取证.md) |
| 大图、封面、曲线与稿差很多 | 图片来源和内容 ID、接口业务值、页面状态；先排除错图/缺数据，不用 CSS 或造假数据追分 | [字体素材与数据](references/字体素材与数据.md) |
| 长名称、窄屏或图表触点异常 | 文本是否是独立图层/列、父容器与子布局、实际画布尺寸及缺值规则 | [几何与组件](references/几何组件与图表.md) |
| 浏览器脚本称失败，原屏却正常 | Uni 自定义 DOM、旧 WebView、原生状态栏坐标、网络事件与渲染帧 | [跨端与取证](references/跨端与取证.md) |

## 一次有效修复的最短闭环

1. **锁定同一状态。** 先读项目任务书、源 Sketch/Figma 图层、组件/页面规范、已验记录和负向候选。固定路由、数据、窗口、DPR、字体、系统栏/安全区、加载完成时机；正式数据与源稿不符时用明确标识的测试夹具复现，或标记不可比。跨页面拼接稿不报单页整幅分数。排除区须预先约定，不能遮掉失败的产品内容。
2. **量差异而非猜样式。** 源图与实屏等比归一；记录容器、文字墨迹、图标的坐标和固定 ROI。先修结构与共享组件，再修来源明确且可分发的素材、字体、颜色和字形。组件共用改动检查所有主要调用态；只有源稿确有差异才写页面局部覆盖。
3. **做单变量可撤销候选。** 核对编译 CSS、计算样式、DOM 几何与截图像素确实改变；不生效的候选无“负向视觉结论”。保持同源、同数据、同裁片和排除区，记录整页及关键区前后值。来源不匹配、仅微小整页增益却造成关键区/窄屏回退的候选应撤回并留档。
4. **以真实目标端收口。** H5 量化只证明浏览器；Android/iOS/鸿蒙的字体、安全区、输入、弹层和 Canvas 另按项目指定设备验。临时 CSS/CDP 截图只是决策线索，正式分数必须来自实际构建/安装制品。多页面改动先合批，针对变化做最小构建与设备复核，复用同源码/制品/环境/范围已有证据。
5. **如实标状态。** 项目若要求整页和全部关键区 SSIM ≥94%，必须逐区达到且人工确认无缺失/遮挡才可称视觉通过；组件通过不自动令调用页通过。窄屏的换行、滚动和真实点击区域也须复核。记录仍未解决的数据、素材、字体、端别与交互边界，不把预览、Mock 或旧包说成正式结果。

案例库按症状分开维护：[几何、共享组件与图表](references/几何组件与图表.md)、[字体、图标、图片与数据](references/字体素材与数据.md)、[跨端差异与取证误判](references/跨端与取证.md)。需要回看项目历史时，先从这些条目的证据目录找原始记录，不全量重读验收库。
