# 图片分析预览优化

目标是减少看图时传输的无关像素和 token，同时不牺牲像素级结论。**预览只用于定位与理解，不能替代原图参与 SSIM、颜色采样、OCR、坐标测量或交付。** 不覆盖、重压或删改原图。

## 每次看图前

1. 先用文件元数据、来源工具或已有记录确认尺寸、字节数、页数/帧数与分析问题；已得到可回答问题的局部证据时，不重复打开整张图。小图（约 ≤100 万像素且 ≤256 KiB）可直接查看，仍保留原图作量化。
2. 本地大图使用 [预览脚本](scripts/prepare_preview.py) 输出长边默认 ≤1600px、总像素 ≤100 万、建议 ≤256 KiB 的 WebP 概览和 JSON 元数据。先看概览以定位问题，再**从原图**按需裁切一两个 ROI；长截图的整页缩略图文字过窄时直接看 ROI，不连续发送整页高清图或所有分片。
3. 指定 ROI 时按原图（EXIF 方向校正后）的像素坐标输入。细字、边框、透明阴影或小图标需要更多像素时提高该 ROI 的预算，必要时直接查看原图局部；不能依据压缩伪影断言颜色、笔画或 1px 几何差异。
4. 比较两图时，保留双方原文件；只为模型观察制作**同一坐标、同一比例**的预览/ROI。正式指标运行在原图或项目规定的无损归一图上，记录裁片与排除区。图片内容、数据状态或源稿尺寸不对应时先解释不可比，不靠拉伸或更换内容取得分数。

示例（先进入本 Skill 的目录；使用带 Pillow 的 Python，桌面环境可先用 `load_workspace_dependencies` 找到工作区 Python）：

```bash
python3 scripts/prepare_preview.py /absolute/path/screenshot.png --output-dir /tmp/image-preview
python3 scripts/prepare_preview.py /absolute/path/screenshot.png --output-dir /tmp/image-preview --roi 120,400,680,500
```

脚本只接受本地栅格图片，不自动下载远程媒体；远程图、连接器返回图片或无本地路径的附件，使用来源工具提供的低细节/裁片能力，不能为了绕过展示限制私自下载。SVG、PDF、动画等先用相应工具选择页面/帧并渲染所需部分；动画脚本只预览首帧且会标警告。正式图片编辑或生成继续使用对应图像工具，此脚本输出仅是分析缓存。

## 决策与留痕

- 预览脚本会输出原图 SHA-256、原/预览尺寸和字节数、ROI、是否有损、是否达预算与警告。`prefer_original_for_view` 为 true 时直接看更省字节的原图；否则仅打开与问题相关的 `preview` 路径。若预算未达或文字不可读，收紧 ROI，而不是继续压低质量。
- 用原图文件链接和原始量化结果写结论；预览可删除，需归档时明确标记为“分析预览”。不要把预览写入产品资源目录或当成用户要求的无损交付图。
- 同时复刻 UI 时再应用 `$ui-design-fidelity` 的源稿/状态/关键区与设备验收规则；本 Skill 只负责控制图片分析开销。
