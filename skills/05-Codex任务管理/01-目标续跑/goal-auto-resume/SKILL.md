# 目标自动续跑

把目标状态与同线程心跳绑定，保留上下文并在后续定时唤醒时继续未完成工作。

## 创建流程

1. 仅在用户明确要求创建目标时创建目标，不从普通任务推断目标。
2. 读取当前目标，确认目标已经创建且尚未完成。
3. 查找当前线程已有的目标续跑心跳；存在时更新，避免重复创建。
4. 使用自动化能力创建绑定当前线程的心跳，不创建独立定时任务。
5. 默认每 30 分钟唤醒一次；用户指定间隔时以用户要求为准。
6. 创建后简要告知心跳间隔、运行位置和停止条件。

## 心跳提示词

使用以下语义生成耐久提示词，可根据目标内容补充必要约束：

```text
继续当前线程中尚未完成的目标。

每次唤醒后：
1. 读取当前目标、已有进展、验证结果和剩余工作。
2. 目标未完成时继续推进，不重复已经完成且验证通过的工作。
3. 如果额度仍未恢复或本轮无法调用模型，不把目标误标为完成；保留续跑心跳，等待下次唤醒。
4. 如果遇到必须由用户选择、授权或提供外部信息的事项，说明具体阻塞并等待用户。
5. 只有目标真正完成且必要验证通过后，才把目标标记为完成。
6. 目标完成后，停止或删除与当前目标绑定的续跑心跳，避免继续唤醒。
```

## 状态与安全

- 心跳不能绕过额度限制；它只负责定时重试，额度恢复后的首次成功运行才会继续目标。
- 本地项目需要电脑开机、Codex 桌面应用运行且项目路径仍可访问。
- 后台任务使用无人值守权限。需要修改项目时使用满足任务所需的最小权限；不要默认扩大到完全访问。
- 用户暂停、停止、删除目标或明确取消自动续跑时，立即暂停或删除对应心跳。
- 如果自动化能力不可用，说明当前不能自动唤醒，并提供手动恢复方式，不伪造已创建状态。
